# Selenium TestNG Automation Framework

This project demonstrates a simple Selenium + TestNG automation framework using the Page Object Model.

## ✅ Tech Stack
- Java
- Selenium WebDriver
- TestNG
- Maven
- WebDriverManager
- Git

## 📂 Project Structure
- `BaseTest.java`: Handles setup and teardown
- `LoginPage.java`: Page Object class
- `LoginTest.java`: Test class using DataProvider

## 🛠 How to Run
```bash
mvn clean test
